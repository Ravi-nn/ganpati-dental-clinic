
# 🦷 Ganpati Dental Clinic Website

Professional website for **Ganpati Dental Clinic** located in Sirsa, Haryana.

## 📋 Project Overview

This is a modern, responsive website designed to establish an online presence for Ganpati Dental Clinic, which previously had zero web presence. The website showcases the clinic's services, contact information, and helps patients book appointments easily.
